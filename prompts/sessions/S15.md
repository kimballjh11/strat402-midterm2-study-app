# Brief: S15 Production I (11 objectives, S15-01 to S15-11)

Sources (sources/text): S15_S15_Slides_Production_I (45 pages; pages 1 to 14 are announcements and spiritual thought, mark non-testable in the ledger), S15_S15_In_Class_Exercise_J_Dawgs (has a Solution sheet), S15_Session_15_Reading_Quiz (in sources/quizzes), S15_Textbook_Study_Notes (secondary), S15_00_Session_Overview, S23_Equation_Sheet.
Refreshers: prereq_S10_Slides_Profit_Maximization (MR equals MC logic), prereq_S05 and STRAT_402_Math_Review (exponents, derivatives).

Must teach, in this order, grounded in the slides:
- Production function Q = F(K, L), inputs, short run (some input fixed) versus long run (all variable). Slides use a "marginal returns to studying" running example, reuse it for intuition.
- Total, average, marginal product. MP = change in Q per extra unit of input, AP = Q/L. Rules: MP above AP pulls AP up, MP below AP pulls it down, MP crosses AP at AP's peak, TP peaks where MP is zero.
- Increasing, decreasing, negative marginal returns, with ranges identified from a table.
- Value marginal product VMP = P x MP and the profit maximizing input rule: hire until VMP = wage (marginal benefit equals marginal cost). Not on the equation sheet. J Dawgs: Q = -0.5L^3 + 4L^2 + 3.5L with capital fixed at 2 grills; hot dog price $4, wage $8. Rebuild the whole table by hand (MP_L, AP_L, value of output, VMP_L versus wage) and state how many workers to hire, using the professor's solution sheet as truth.
- Linear Q = aK + bL (constant MP, perfect substitutes), Leontief Q = min(aK, bL) (fixed proportions, perfect complements, zero marginal product of the extra input), Cobb-Douglas Q = K^a L^b (MP_K = aK^(a-1)L^b and MP_L = bK^a L^(b-1), on the sheet). Characteristics of each (shape of isoquants, MP behavior, substitutability, returns to scale from a+b for Cobb-Douglas). The slides compare all three and have an exponent simplification math review: teach it.
Math refreshers needed: power rule, partial derivative holding the other input fixed, exponent rules including negative and fractional exponents, solving a linear equation, computing MP numerically from a table.
Calculation objectives (calc true): S15-04, S15-05, S15-06 (VMP), S15-10 (profit maximizing input), S15-09 (Cobb-Douglas MP), and any linear or Leontief MP question.
Graphs: production component (TP, AP, MP, three stages, VMP versus wage). Default params from J Dawgs.
Generators (at least): MP and AP from a cubic production function at a given L; L that maximizes TP; profit maximizing L given P, w and a table or cubic; Cobb-Douglas MP_K and MP_L at given K and L; Leontief output from fixed proportions; returns to scale from exponents.
Practice exam relevance (study guide column): Q1, Q2, Q3, Q15 to Q17 touch these objectives, so expect case style questions on VMP and MP and Cobb-Douglas.
