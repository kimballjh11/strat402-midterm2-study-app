# Brief: S16 Production II (6 objectives, S16-01 to S16-06)

Sources: S16_S16_Slides_Production_II (43 pages), S16_S16_In_Class_Exercise_Cost_Minimization (docx with solutions in the second half), S16_S16_In_Class_Exercise_Production_Functions (4 sheets: Linear, Cobb-Douglas, Leontief, Changing Levels of Production), S16_Production_Exercise_Klarna_Canvas_latest (use the Canvas latest version, Exercise sheet 214 rows, uses Solver and a log-linear regression: Solver and Excel are not allowed on the exam, so teach the by-hand method and mention the regression only as far as the slides do), reading quiz, secondary notes.
Images worth viewing: S16/Images/Cost Minimization Tangency.png, Isoquant 3D Surface.png.

Must teach:
- Isoquant: all input combinations that give the same output. Shapes for linear (straight line), Leontief (L shape), Cobb-Douglas (smooth, convex). Higher isoquants farther from the origin.
- MRTS (as defined on the equation sheet: MRTS_KL = MP_L / MP_K), slope of the isoquant in absolute value, rate at which one input substitutes for the other holding output constant. Law of diminishing MRTS and why it holds for Cobb-Douglas and not for linear.
- Isocost: C = wL + rK, slope -w/r (on the sheet), intercepts C/w and C/r, how it shifts when budget changes and rotates when a price changes.
- Cost minimizing input rule: MP_L / w = MP_K / r, equivalent to MRTS = w/r, tangency of isoquant and isocost. "Bang for the buck" language from the in-class exercise. Not on the sheet beyond MRTS and the isocost slope, so teach it as a rule to memorize.
- Worked in-class exercise: w = $12, MP_L = 84, r = $15, MP_K = 120, so MP_L/w = 7 and MP_K/r = 8, not cost minimizing, use more capital and less labor. Include the graph of the shift when the rental rate rises (capital falls, labor rises).
- Optimal input substitution: when relative input price changes, how the cost minimizing mix moves. For Cobb-Douglas Q = K^a L^b: set b K / (a L) = w/r so K = (a w)/(b r) L, then substitute into Q to solve for L and K at a target output. Teach this fully by hand with clean numbers. Corner solutions for linear production (use only the input with the higher MP per dollar), kinked for Leontief (inputs in fixed proportion, cost is then just the sum).
Math refreshers: ratios and slopes, solving two equations in two unknowns, substitution, exponents.
Calculation objectives: S16-02 (MRTS), S16-04 (isocost), S16-05 (cost minimizing rule), S16-06 (optimal substitution).
Graphs: isoquant component, costmin component with sliders for w, r and output target.
Generators: MRTS for Cobb-Douglas at a point; is a bundle cost minimizing from MPs and prices; cost minimizing K and L for Cobb-Douglas given w, r, Q (clean exponent cases such as K^0.5 L^0.5); isocost intercepts and slope; effect of a price change on the mix; cheapest input for linear production.
